# Japanese Study Card – AR 단어 학습 앱

### 🖊️ 요약

- Unity의 **AR Foundation**으로 제작된 일본어 단어 교육 카드 앱
- 전용 모바일 앱에서 **카드 뒷면의 QR코드**를 인식 → 해당 단어에 해당하는 **3D 오브젝트** 출력
- **2022년도 3학년 1학기**, 일본학과 캡스톤디자인1 프로젝트

### 🗓️ 개발 기간

- **2022.3 ~ 2022.6** (3학년 1학기)


### 👨🏻‍🔧 역할
- **총 6인 팀 구성**  
  - 기획 담당: 2명  
  - 카드 실물 제작: 2명  
  - 발표 담당: 1명  
  - **앱 개발 담당: 1명**

 - **주요 담당 업무**
   - AR 시스템 구현
   - 3D 모델 애니메이팅
   - 모바일 빌드 및 테스트
   - QR코드 생성 및 연동

### 🙋🏻‍♂️ 감상

*Japanese Study Card*는 6인 협업 프로젝트로, 개발담당으로서 전체 앱의 기술 구현을 전담하였습니다.  
팀원 간, 개발 프로스세스의 이해 차이로 인해 기획과 개발 간 조율이 필요했던 순간도 있었지만 적극적인 소통과 협의를 통해 각자의 역할을 조화롭게 이끌어낼 수 있었습니다.  
이 경험은 단순한 개발을 넘어 **비개발자와의 협업 역량**, 문제 해결을 위한 **유연한 커뮤니케이션 스킬**, 그리고 프로젝트를 끝까지 완수하는 **리더십**까지 함께 성장할 수 있었던 소중한 계기가 되었습니다.
