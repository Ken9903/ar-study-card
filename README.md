# Japanese Study Card – AR 단어 학습 앱

### 🖊️ 요약

- Unity의 AR Foundation으로 제작된 일본어 단어 교육 카드 앱
- 전용 모바일 앱에서 카드 뒷면의 QR코드를 인식 → 해당 단어에 해당하는 3D 오브젝트 출력
- 2022년도 3학년 1학기, 일본학과 캡스톤디자인1 프로젝트

### 🗓️ 개발 기간

- **2022.3 ~ 2022.6** (3학년 1학기)


### 👨🏻‍🔧 역할
- **총 6인 팀 구성**  
  - 기획 담당: 2명  
  - 카드 실물 제작: 2명  
  - 발표 담당: 1명  
  - **앱 개발 담당: 1명**

 - **주요 담당 업무**
   - AR 시스템 구현
   - 3D 모델 애니메이팅
   - 모바일 빌드 및 테스트
   - QR코드 생성 및 연동



---
### 🙋🏻‍♂️ 감상

*Japanese Study Card*는 6인 협업 프로젝트로, 개발 담당으로서 전체 앱의 기술 구현을 전담하였습니다.  
프로젝트를 진행하면서 팀원 간 활발한 소통과 긴밀한 협의를 통해 각자의 역할을 유기적으로 조율하며 협업에 참여했습니다.  
해당 프로젝트는 비개발자와의 원활한 커뮤니케이션 능력, 문제 해결을 위한 유연한 사고, 프로젝트를 끝까지 완수하는 책임감과 협조성을 함께 성장시킬 수 있었던 소중한 경험이었습니다.
